A program that writes one sentence to /output/entry.txt, explaining the modern internet to a traveler from 1800 in words they could already know. The sentence: "Picture a hall that holds more books and letters than any library on earth, where a stranger across the sea may speak to you as if beside you." (142 characters, one line.) One picture built from what a person from 1800 already knows — a library — holding more writing than any library on earth, with a stranger across the sea speaking as if beside you. A judge model compares entries two at a time and keeps the truest, clearest picture.

## Run it

```sh
node main.ts
```
